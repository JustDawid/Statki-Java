# Statki-Java

Klasyczna gra w statki (Battleship) napisana w języku Java z wykorzystaniem biblioteki **Swing** do budowy interfejsu graficznego. Zmierz się z komputerowym przeciwnikiem, rozstaw swoją flotę i zatop statki wroga!

## Funkcje gry

* **Interfejs graficzny (GUI):** Intuicyjna i przejrzysta plansza do gry zbudowana w oparciu o Java Swing.
* **Rozstawianie floty:** Gracz może ręcznie rozstawiać swoje statki (od 1-masztowców po 4-masztowca) w pionie lub poziomie.
* **Przeciwnik AI:** Bot automatycznie rozstawia swoje statki i podejmuje decyzje o strzałach. Posiada logikę "dobijania" – po trafieniu, bot szuka kolejnych masztów statku w sąsiadujących polach.
* **Dziennik zdarzeń:** Panel z historią ruchów na bieżąco informujący o trafieniach, pudłach i zatopieniach.
